# anvil-chain-primer

自分で暗号通貨のチェーンを運用する、初歩の演習です。[Foundry](https://getfoundry.sh/) の `anvil` で、Ethereum と同じ形のチェーンを自分のパソコンの中に立て、運営する側の立場で 3 つのことを確かめます。

- 自分のパソコンの中だけで動きます。外のチェーンには何も送りません。資金は動きません。
- 秘密鍵を打ちこむ手順はありません。
- 所要は 20〜30 分です。上から順にコマンドを打てば進みます。
- 書いたのは DeFi を学び始めたばかりの個人です。学習の記録として公開しています。

> **免責**: このリポジトリは学習用です。投資の助言ではありません。ここで動かすのは、開発や実験のための、1 台だけのチェーンです。多くのノードが合意を取りながら動く本物のチェーンの運用（バリデーターなど）は扱いません。

## なぜ自分でチェーンを持つのか

ふだんチェーンを使うときは、利用者として取引を送るだけです。残高も、時刻も、取引の順番も、自分では決められません。

自分でチェーンを動かすと、立場が逆になります。残高を好きに決め、世界を巻き戻し、ブロックを作るタイミングを選べます。コントラクトの開発、取引のボットの試験、過去の場面の再現は、どれもこの立場を使っています。この演習は、その入口です。

## 要るもの

- **Foundry**（`anvil`、`forge`、`cast`）。入れ方は [公式の手順](https://getfoundry.sh/) にあります。この演習は 1.8.3 で確かめました。
- **Python 3**。`helpers.sh` が、結果を読みやすく並べるのに使います（標準ライブラリだけ）。
- macOS か Linux のターミナル（`bash` か `zsh`）。確かめたのは macOS の `zsh` です。

入っているかどうかは、こう確かめます。

```bash
anvil --version
```

## 準備

```bash
git clone https://github.com/aobathree/anvil-chain-primer.git
```

ターミナルのタブを 2 つ使います。

**タブ 1（anvil を動かしたままにする）**

```bash
anvil --port 8546 --order fees
```

- `--port 8546`: anvil の既定のポートは 8545 です。ほかの anvil とぶつからないように、1 つずらしています。
- `--order fees`: 「ブロックの中の順番を、手数料の高い順にする」という指定です。これは anvil の既定の値ですが、演習 3 の主役なので、はっきり書いています。

起動すると、口座 10 個（それぞれ 10,000 ETH）と、`Listening on 127.0.0.1:8546` が出ます。

**タブ 2（ここにコマンドを打つ）**

```bash
cd anvil-chain-primer
```

```bash
source helpers.sh
```

`helpers.sh` は、つなぎ先（`ETH_RPC_URL`）を 8546 に決め、演習 3 で使う `show_pool` と `show_block` を用意します。

口座を 2 つ、変数に入れます。

```bash
A=0xf39fd6e51aad88f6f4ce6ab8827279cfffb92266
```

```bash
B=0x70997970c51812dc3a010c7d01b50e0d17dc79c8
```

これは anvil の 1 つめと 2 つめの口座です。`cast rpc eth_accounts` で確かめられます。

ここまでできたら、[演習 1](docs/01_own_chain.md) に進みます。

## 安全について

- **練習用の口座の鍵は、世界中に知られています。** anvil が最初に出す口座と秘密鍵は、だれの anvil でも同じです。本物のチェーンでこの口座に資金を送ると、すぐに抜かれます。**本物のチェーンでは絶対に使わないでください。**
- この演習では、鍵を打ちこみません。`--unlocked` という指定で、署名を anvil にまかせます。これは、鍵を持つノードが自分の手元にあるからできることです。
- anvil を止めると、状態はすべて消えます。やり直したいときは、タブ 1 で Ctrl+C を押して止め、「準備」から始め直します。

## 後片づけ

タブ 1 で Ctrl+C を押して、anvil を止めます。

## 3 つの演習で分かること

| | 利用者の立場 | 運営する側の立場 |
|---|---|---|
| 残高・コントラクトの中の値 | 取引を送って、決まりのとおりに変える | 直接書きかえられる |
| 時刻・ブロックを作るタイミング | 決められない | 自分で決める |
| やり直し | できない | 印をつけて、巻き戻せる |
| mempool の中身 | 自分のノードがなければ見えない | 全部見える |
| ブロックの中の順番 | 手数料で入札する | 並べ方の決まりを選ぶ |

置いたコントラクトの計算は、本物のチェーンと同じです。ちがうのは、中の値と、時間と、順番を、運営する側が決めていることです。手元のチェーンでの試験の結果を読むときは、この点を覚えておくと役に立ちます。
