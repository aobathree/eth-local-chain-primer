# eth-local-chain-primer

**鋳造所の見習いになって、自分の Ethereum のチェーンを動かしてみる** 入門の演習です。

Ethereum は、Bitcoin とちがって「みんなで使う 1 台のコンピューター」です。そのコンピューターのためのプログラムを作る道具のセットに、**Foundry（鋳造所）** という名前が付いています。中の道具も、anvil（金床）、forge（鍛造する）、cast（鋳造する）、chisel（たがね）と、鉄の製品を作る仕事の言葉でそろっています。

この演習では、その鋳造所を自分のパソコンの中に開いて、見習いとして 1 日働きます。

- 自分のパソコンの中だけで動きます。外のチェーンには何も送りません。資金は動きません。
- 秘密鍵を打ちこむ手順はありません。
- 所要は 30〜40 分です。上から順にコマンドを打てば進みます。
- 書いたのは DeFi を学び始めたばかりの個人です。学習の記録として公開しています。

> **免責**: このリポジトリは学習用です。投資の助言ではありません。ここで動かすのは、開発や実験のための、1 台だけのチェーンです。多くのノードが合意を取りながら動く本物のチェーンの運用（バリデーターなど）は扱いません。

## はじめに: なぜ「鋳造所」なのか

### 1. Bitcoin は台帳、Ethereum はコンピューター

Bitcoin（BTC）がしていることは、ひとことで言えば「だれがいくら持っているか」の台帳を、みんなで守ることです。

Bitcoin にも、支払いの条件を書くための小さな言語（Script）があります。ただし、できることは、わざとしぼってあります。Ethereum のホワイトペーパーは、Bitcoin の言語に足りないものとして、まず **くり返し（ループ）が書けない** ことを挙げています。検証が終わらなくなるのを防ぐためです。

Ethereum は、ここを変えました。ホワイトペーパーの言い方では、「チューリング完全なプログラミング言語を組みこんだブロックチェーン」です。Bitcoin にはない、3 つのものを持っています。

| Ethereum が持つもの | 中身 |
|---|---|
| **フルのコンピューターの機能** | くり返しも、条件の分かれも書ける。台帳の書きかえだけでなく、好きな決まりをプログラム（**コントラクト**）にして、チェーンの上に置ける |
| **そのための言語** | 人が読み書きする言語として **Solidity** がある |
| **仮想の計算機（VM）** | Solidity のプログラムを実行する計算機 **EVM**（Ethereum Virtual Machine）が、すべてのノードに入っている |

取引所も、貸し借りも、NFT も、この「コンピューター」の上で動くプログラムです。

- **ETH と Ethereum**: Ethereum がチェーン（コンピューター）の名前、ETH はその上の通貨の名前です。ETH は、計算の手数料（ガス代）を払うのにも使います。
- **終わらないプログラムはどうするのか**: Bitcoin は「くり返しを書けなくする」ことで防ぎました。Ethereum は「計算した分だけ手数料（ガス）を払う」ことで防ぎます。払った分のガスを使い切ると、計算は止まります。

### 2. コンピューターには、プログラムを作る場所が要る

コンピューターがあれば、プログラムを作る人が出てきます。ただ、Ethereum のプログラムには、ふつうのプログラムとちがう、こわい点があります。

- チェーンに置いたコードは、あとから書きかえられません。
- 置いたとたんに、世界中のだれでも呼べます。
- 資金を預かることがあります。

だから、本物のチェーンに置く前に、**手元で作って、何度もたたいて試す場所** が要ります。その道具のセットの代表が **Foundry** です（同じ役目の道具に、Hardhat などがあります）。

**foundry は、英語で「鋳造所」です。** 金属を溶かして、型に流しこんで、鉄の製品（鋳物）を作る工場のことです。Foundry の [リポジトリ](https://github.com/foundry-rs/foundry) を開くと、いちばん上に、溶けた金属が流れ落ちる鍋のあいだで、ハンマーとやっとこを持った職人が立っている絵があります。

### 3. 道具の名前は、どれも鉄の仕事

Foundry を入れると、4 つの道具が使えるようになります。名前は、どれも鉄の製品を作る仕事の言葉です。

| 道具 | 英語の意味 | 鋳造所での役目 | Ethereum での役目 |
|---|---|---|---|
| **anvil** | 金床（かなとこ） | 熱した鉄をのせて、たたくための台 | 手元で動く、自分だけのチェーン。プログラムをのせて試す台 |
| **forge** | 鍛造する | 熱した鉄をたたいて、形にする | Solidity のプログラムを組み立てて、チェーンに置く |
| **cast** | 鋳造する | 溶かした鉄を型に流しこんで、形にする | 決まった型のコマンドで、チェーンを読む・取引を送る |
| **chisel** | たがね | けずって、細かく形を整える | Solidity を 1 行ずつ試す |

forge（鍛造）と cast（鋳造）は、鉄の製品の作り方を表す、対になる動詞です。たたいて作るのが forge、溶かして型に流すのが cast です。

名前の意味は英語のとおりです。「鋳造所での役目」と「Ethereum での役目」の重ね方は、この演習を書いた側の読み方です（Foundry の README とサイトのトップページには、名前を付けた理由は書かれていませんでした）。

### 4. この演習ですること

ふだん、わたしたちはチェーンの **利用者** です。取引を送るだけで、残高も、時刻も、取引の順番も、自分では決められません。

鋳造所の中に入ると、立場が逆になります。金床（チェーン）は自分のものです。残高を好きに決め、世界を巻き戻し、ブロックを作るタイミングを選べます。**運営する側から見ると、チェーンがどういうしかけで動いているかが、よく分かります。**

## 見習いの 1 日

| 話 | 読み物 | 使う道具 | すること |
|---|---|---|---|
| 準備 | [道具をそろえる](docs/00_setup.md) | — | Foundry を入れて、このリポジトリを手元に置く |
| 第 1 話 | [金床を据える](docs/01_own_chain.md) | anvil、cast | 自分のチェーンを立てる。持ち主だけができること（残高の書きかえ、巻き戻し、時計を進める）を試す |
| 第 2 話 | [鍛えて、金床にのせる](docs/02_deploy.md) | forge、cast、chisel | Solidity のプログラムをチェーンに置く。置いたものを読む・書く |
| 第 3 話 | [金床の前の行列](docs/03_mempool.md) | cast | 順番を待つ取引の列（mempool）をのぞく。先に打ってもらえるのは、先に来た人ではなく、多く払った人 |
| 辞書 | [用語集](docs/glossary.md) | — | 道具と言葉の意味、名前の由来 |

**準備 → 第 1 話 → 第 2 話 → 第 3 話の順に、同じ anvil を動かしたまま進めてください。** 後ろの話は、前の話で作った状態（置いたプログラム、ブロックの番号）を使います。

## 安全について

- **練習用の口座の鍵は、世界中に知られています。** anvil が最初に出す口座と秘密鍵は、だれの anvil でも同じです。本物のチェーンでこの口座に資金を送ると、すぐに抜かれます。**本物のチェーンでは絶対に使わないでください。**
- この演習では、鍵を打ちこみません。`--unlocked` という指定で、署名を anvil にまかせます。これは、鍵を持つノードが自分の手元にあるからできることです。
- anvil を止めると、状態はすべて消えます。やり直したいときは、anvil を Ctrl+C で止めて、第 1 話の最初から始め直します。

## 1 日を終えると分かること

| | 利用者の立場 | 運営する側の立場（金床の持ち主） |
|---|---|---|
| 残高・プログラムの中の値 | 取引を送って、決まりのとおりに変える | 直接書きかえられる |
| 時刻・ブロックを作るタイミング | 決められない | 自分で決める |
| やり直し | できない | 印をつけて、巻き戻せる |
| 順番を待つ列（mempool）の中身 | 自分のノードがなければ見えない | 全部見える |
| ブロックの中の順番 | 手数料で入札する | 並べ方の決まりを選ぶ |

置いたプログラムの計算は、本物のチェーンと同じです。ちがうのは、中の値と、時間と、順番を、運営する側が決めていることです。手元のチェーンでの試験の結果を読むときは、この点を覚えておくと役に立ちます。
